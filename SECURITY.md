# Publishing and security

This project contains the standalone WordPress companion plugin only. It does not include Bit Form Free/Pro distributions, site data, customer submissions, server logs, email logs, tokens, API keys, WordPress configuration, or SMTP credentials.

Grant access only to authorized WordPress administrators. Back up before upgrading, test on staging, and review changes before deploying. If the underlying Bit Form or PHP/mPDF version changes, re-test recipient routing and PDF attachments before production use.
